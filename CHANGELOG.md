# Changelog

## 0.1.0 — first public version

- Compare two orgs authenticated in the Salesforce CLI. No credentials are requested or stored.
- 10 QA categories: profiles & permission sets (incl. FLS), validation rules, flows (active state and
  logic), custom settings values, custom metadata values, record types, page layout assignments,
  feature settings & org sharing defaults, custom fields, named credentials & remote site settings.
- QA impact ranking (High / Medium / Low) with plain-language explanations.
- Report view with a "High impact only" filter, plus Markdown/HTML export for bug tickets.
- English and Spanish.
- 100% local: no backend, no telemetry. Network traffic goes only to your own orgs, on Salesforce domains.
